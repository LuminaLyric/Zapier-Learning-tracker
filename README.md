# Automated Learning Tracker with Zapier

## Overview
Built an automation workflow using Google Forms and Zapier to capture submissions and organize learning records automatically.

## Tools Used
- Google Forms
- Zapier

## Workflow
Google Form Submission
↓
Zapier Trigger
↓
Automated Record Added to Learning Tracker
